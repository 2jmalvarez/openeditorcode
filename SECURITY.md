# Security

Please do not post credentials, private keys, project files, recovery drafts or
unredacted logs in public issues. Use GitHub's private vulnerability reporting
when available; otherwise contact the maintainer with a non-sensitive summary
to arrange a private channel. If a credential has been exposed, revoke/rotate it
at its provider; deleting a file or a Git commit does not revoke the credential.

See [security and privacy controls](docs/security.md) for current safeguards,
their limitations and verification commands. These changes in the source tree
are not present in older npm packages until a new release is published.
